# Gezinti

Gezi planı, bütçe, bavul ve ev kontrol listeleri tek yerde. Durakları elle ya da kendi AI'ınla (Claude, ChatGPT, Gemini) planla; eşinle ya da arkadaşlarınla ortak kullan.

Ayrıca: yaşa göre **bebek çantası** listesi, **evden çıkarken** kontrol ve yanına alacakların listesi, alarmlı **hatırlatmalar**.

Kullan: https://sozenn.github.io/gezi/
